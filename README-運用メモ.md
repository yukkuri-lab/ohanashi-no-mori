## いちばん大事：Googleの鍵に制限をかける（未実施なら最優先）

読み上げの声は Google の有料サービスを使っています。
その鍵（APIキー）が野放しだと、他人に使われて**タカさんに請求が来ます**。

アプリ側にも歯止めを入れましたが（後述）、**本当の防御はGoogle側の設定です。**
これは管理画面での作業なので、タカさんの手でお願いします。

### 手順

1. https://console.cloud.google.com/ を開く
2. 左メニュー →「APIとサービス」→「認証情報」
3. このアプリで使っている APIキー をクリック
4. **「アプリケーションの制限」は「なし」のままにする**
   - ⚠️ **HTTPリファラー制限は選ばないこと。**
     この鍵はブラウザではなく**サーバーから**使っています。サーバーからの通信には
     リファラ情報が付かないため、この制限をかけると音声が一切出なくなります。
     （2026-08-22、実際にこれで本番の音声が止まりました）
   - ブラウザに鍵が出ることは無いので、この制限は元々効き目がありません
5. **「APIの制限」→「キーを制限」を選び、「Cloud Text-to-Speech API」だけにチェック**
   - これで、万一漏れても他のサービスには使えなくなります
6. 保存

### 訂正：「1日あたりの文字数上限」は設定できません

以前ここに「割り当てで1日10万文字にする」と書いていましたが、**間違いでした。**
Cloud Text-to-Speech の割り当ては、実際に画面で確認したところ
**すべて「per minute（1分あたり）」**で、1日あたりの枠はありません。

お金の歯止めとして実際に効くのは、次の「予算アラート」です。

### 予算アラート（設定済み・2026-08-22 確認）

お支払い → 予算とアラート に、すでに設定がありました。

| 項目 | 内容 |
|---|---|
| 名前 | ¥100 1か月の予算のアラート |
| 金額 | 月100円 |
| 対象 | すべてのプロジェクト（3個）・すべてのサービス |
| 種類 | **アラートのみ**（メールが届くだけ。サービスは止まりません） |
| 通知 | 50% / 90% / 100% / 150%（＝50円・90円・100円・150円で通知） |

Google Cloud 全体をカバーしていて、金額も十分に低いので、**追加の設定は不要**と判断しました。

なお「利用額上限の適用」を選ぶと、超えた時点でサービスが実際に止まります。
ただし**その場合、子どもが使っている最中にアプリが止まる**ので、今回は選んでいません。

## アプリ側に入れた歯止め（2026-08-22 追加）

`src/app/api/speak/route.ts` に3つ入っています。

| 何を | どれくらい | 目的 |
|---|---|---|
| 1回の文字数制限 | 500文字まで | 1回で大量に読ませない |
| 回数制限 | 1分間に60回まで | 連打・スクリプトを止める |
| 1日の文字数上限 | 20万文字 | 請求の天井 |

数字を変えたいときは、そのファイルの上のほうにある
`RATE_MAX_REQUESTS` と `DAILY_CHAR_BUDGET` を書き換えてください。

### 正直に書いておくこと

「どのサイトから来たか」の確認は入れていますが、**これは完全な鍵ではありません。**
その気になれば偽装できる仕組みだからです（ブラウザ以外から呼ぶ場合）。

なので、上の「Google側の制限」が本命です。**アプリ側の歯止めは、その補助**だと考えてください。

## 公開先のドメインを変えたとき

Vercel の環境変数 `ALLOWED_ORIGIN` を書き換えてください。
**カンマ区切りで複数書けます。**

```
ALLOWED_ORIGIN=https://ohanashi-no-mori.vercel.app,https://ohanashinomori.com
```

書いたドメインと**完全に一致**したものだけを通します。

## 子どものデータについて

このアプリが端末に残すのは、この2つだけです。外部には送っていません。

- **学習の記録**（開いた回数・読んだ回数・正解数）… ブラウザの localStorage
- **録音した声**… ブラウザの IndexedDB

### 消し方

- **1つのおはなしの録音だけ消す**: 読み終わりの画面 →「ろくおんを けす 🗑」
- **全部消す**: タイトル画面の左下「おうちのかたへ」→ 確認して消す

「おくる（シェア）」を押したときは、スマホの共有画面が出るだけで、
**どこに送るかはタカさんが選びます。** 勝手にどこかへ送ることはありません。

## 部品の更新について

2026-08-22 に、土台（Next.js）を 14.2.5 → 14.2.35 に上げました。
危険度「最高」の問題が報告されていたためです。

`postcss` という部品に、まだ危険度「高」の問題が2件残っています。
これは Next.js が内部で抱えているもので、**直すには Next.js 16 への大型更新が必要**です。
中身はサイトを組み立てるときだけ使う部品で、
**訪問者が攻撃に使えるものではない**ため、いったん保留にしています。

年に1回くらい、`npm audit` で状況を見直すといいです。
